Windows 98 win98

任务栏 + 开始菜单详细信息视图

打开 →
Argon argon

居中正文栏悬停浮起

装到自己的 ani-rss 上

脚本会问装哪一款、装到哪个目录，在线播放器一并装好。

Linux / NAS curl -fsSL https://raw.githubusercontent.com/zzzwannasleep/ani-rss-themes/main/install.sh | bash
Windows irm https://raw.githubusercontent.com/zzzwannasleep/ani-rss-themes/main/install.ps1 | iex
⚠️

装完要重启 ani-rss，光刷新页面不生效。 程序只在启动时扫一次配置目录下的 webui/，而且 index.html 必须直接躺在这一层， 多套一层目录会被当成空文件夹、静默用回自带界面。想还原：清空该目录再重启。
