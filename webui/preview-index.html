WebUI 预览

五款界面，同一套功能。点开就能试，数据是内置的假数据，改什么都不会保存。

窄屏也能看 —— 这五款是同一套响应式代码，不是另做的手机版。

二次元
壁纸打底的海报墙，外壳半透明浮在图上，窄屏走底部导航
海报墙 · 每次刷新换壁纸
液态玻璃
导航是一枚悬浮的玻璃胶囊，内容是一张张横躺的大圆角卡
悬浮岛 · 按下回弹
Vue 文档
文档站的路子：左侧分组导航 + 居中正文，靠细线分栏不靠阴影
分组侧栏 · 信息密度适中
GitHub
Primer 的路子：深色顶栏 + 一排 tab，内容是一张带边框的清单
无侧栏 · 打开就干活
Material Design 3
宽屏导航栏杆 + 窄屏底部导航，扩展 FAB 常驻右下
M3 响应式导航 · FAB

装到自己的 ani-rss 上（Linux / macOS / NAS）：

curl -fsSL https://raw.githubusercontent.com/zzzwannasleep/ani-rss-themes/main/install.sh | bash

Windows PowerShell：irm https://raw.githubusercontent.com/zzzwannasleep/ani-rss-themes/main/install.ps1 | iex

脚本会问装哪一款、装到哪个目录，在线播放器一并装好。装完刷新 ani-rss 页面即可， 想还原就把 webui 目录清空。
